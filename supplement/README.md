# Supplement: Same Text, Different Transitions

Anonymous supplementary material for the paper. This package contains the
released experimental records, analysis code, Lean replay harnesses, exact
configuration pins, and a copy of the paper used to assign table and appendix
numbers.

## Reviewer quick start

The headline results can be recomputed from the released records without Lean,
model weights, network access, or a GPU:

```bash
cd supplement
./reproduce.sh all
```

Python 3 and SciPy are sufficient for this saved-record reproduction. If SciPy
is unavailable:

```bash
python3 -m pip install scipy==1.16.3
```

The command exits nonzero on missing input or analysis failure. A successful
run prints every main-paper result and the principal appendix controls. The
expected values and their paper locations are listed in
[`EXPECTED_RESULTS.md`](EXPECTED_RESULTS.md).

Individual result families can be checked in seconds:

```text
./reproduce.sh witness         motivating pair, Table 1
./reproduce.sh regimes         discovery regimes, Table 2
./reproduce.sh classes         70-class corpus summary
./reproduce.sh representation  learned structural channel, Tables 3 and 4
./reproduce.sh direct          frozen 7B test, Table 5
./reproduce.sh sweep           candidate-width sweep, Table 6
./reproduce.sh stress          alias stress benchmark, Table 7
./reproduce.sh persist         current-stack blind incidence and persistence
./reproduce.sh rerank          auxiliary fixed-candidate reranking
./reproduce.sh policies        auxiliary multi-generator exposure
./reproduce.sh cost            structural-identity cost decomposition
./reproduce.sh natural         repeats in human Mathlib proofs
./reproduce.sh repsens          independent member searches
```

## Package layout

```text
supplement/
  README.md                 this guide
  EXPECTED_RESULTS.md       paper-to-record result map
  MANIFEST.sha256           integrity hashes for all other files
  reproduce.sh              saved-record analysis entry point
  requirements.txt          pinned full experimental Python environment
  config.yaml               corpus, model, seed, and replay configuration
  Fingerprint.lean          reference structural fingerprint exporter
  audit/                    shared extraction, replay, and model code
  tools/                    experiment and analysis entry points
  tests/                    110-test analysis and harness verification suite
  data/                     released JSON and JSONL records
  paper_src/                paper PDF and buildable LaTeX source
```

Class identity is `(theorem, pp_hash)`. Root identity is
`(file, theorem, tactic_index)`. Confirmed classes are deduplicated across
sampling regimes by class identity.

## Released records

The primary historical configuration is Mathlib commit
`29dcec074de168ac2bf835a77ef68bbe069194c5`, Lean `v4.10.0-rc1`, and
LeanDojo 2.0.2. The current-stack audit uses Mathlib commit
`3b3cdbb692938d509d6fb29fc5e50638985aecf1` and Lean `v4.33.0-rc1`.

The frozen direct test pins BFS-Prover-V2-7B snapshot
`533d59fc6b5e04ae6e2c25f1d88cf921061169d0`. The candidate-width sweep pins
miniCTX snapshot `7c00b1175a82ea993732e5eff727b300e7589bb5`, uses one deterministic
beam-16 list per alias class, and defines smaller candidate sets as nested
prefixes.

Each discovery run contains `roots.shard*.jsonl`, `stageb.shard*.jsonl`,
`confirmation.json`, and `mechanism.json`. Confirmation records retain repeat
tables, exclusions, and nondeterministic outcomes. The representation, direct
model, candidate, retention, cost, and search directories contain the exact
per-example or per-search rows consumed by `reproduce.sh`.

## Re-running Lean and model experiments

Full regeneration is optional for paper verification and substantially more
expensive. Install the pinned environment with:

```bash
python3 -m venv .venv
. .venv/bin/activate
python3 -m pip install -r requirements.txt
```

LeanDojo requires a GitHub token for repeated repository and toolchain
resolution. Export `GITHUB_ACCESS_TOKEN` directly, or set
`GITHUB_TOKEN_FILE` and invoke commands through
`tools/with_github_token.sh`. No credential is stored in this package.

The 168,074-state historical corpus is approximately 205 MB and is omitted
from the archive. It can be regenerated by tracing the pinned Mathlib commit
with LeanDojo. Scripts that restore historical states accept it through
`--states`. The current-stack extraction procedure is implemented in
`tools/prepare_current_stack.py`, `tools/current_blind_extract.py`, and
`tools/current_reconvergence.py`.

The current alias stress benchmark can be rerun with:

```bash
python tools/alias_stress_benchmark.py \
  --repo /path/to/mathlib4-at-3b3cdbb \
  --out data/alias_stress
```

It compiles every candidate state and action label, enumerates both arrival
orders, and uses seed `731991` for randomized-order checks. Other harnesses
take fixed seeds from `config.yaml` or their command-line defaults. Resource
failures and exclusions remain present in the released records.

## Scope and anonymity

The package contains no author names, credentials, private filesystem paths,
symlinks, model weights, or compiled Mathlib checkout. It includes only source,
configuration, paper material, and experiment records needed for anonymous
review. File integrity can be checked with:

```bash
shasum -a 256 -c MANIFEST.sha256
```

The source and analysis suite can be checked with the pinned pytest version:

```bash
python3 -m pytest -p no:cacheprovider -q
```
